# Руководство пользователя Smart Support Hub

Приложение предназначено для демонстрации работы небольшой команды сопровождения программного продукта. Данные сохраняются **только в том браузере, в котором вы их вводите**.

## Открытие проекта

Откройте сайт через локальный веб-сервер, например по адресу http://127.0.0.1:8765/. В меню слева находятся пять разделов. На узком экране меню открывается кнопкой в верхней панели.

## Регистрация инцидента

1. Откройте **Инциденты**, нажмите **+ Новое обращение**.
2. Введите краткое название проблемы и выберите приоритет: критический, высокий, средний или низкий.
3. Нажмите **Зарегистрировать**. Если название пустое, появится подсказка. После ввода текста она исчезнет.
4. В журнале обращение получит ID и срок SLA.

Срок решения зависит от приоритета: 4, 8, 24 или 72 часа. В таблице отображается состояние SLA. Кнопка **В работу** переводит новое обращение в обработку; **Решить** закрывает его с текущей датой решения.

Вверху журнала есть быстрые вкладки **Все**, **Новые**, **В работе**, **Решённые**. Слева под ними работают дополнительные фильтры по статусу и приоритету. Поиск принимает название обращения или ID; клавиша `/` ставит курсор в поле поиска, если вы не редактируете другую форму.

## Внедрения

Откройте **Внедрения** и нажмите **+ Новое внедрение**. Укажите заказчика, продукт, номер версии, ответственного, этап, дату, количество выполненных и общее количество задач. После сохранения новая запись появится в таблице; процент готовности рассчитан автоматически.

## Заявки на изменения

Откройте **Заявки**, нажмите **+ Новая заявка**. Заполните название, выберите вид сопровождения и целевую версию. Поддерживаются corrective, adaptive, perfective, preventive. Статус можно менять из таблицы.

## Релизы

На странице **Релизы** видна история изменений. **+ Новый релиз** открывает форму с типами Patch / Minor / Major и полем для описания изменений. Новая версия вычисляется автоматически на основании последнего выпуска.

## Главная панель и темы

**Панель** показывает активные внедрения, открытые инциденты, процент соблюдения SLA и текущую версию продукта. Столбчатый график показывает количество обращений по приоритетам; кольцевой график — распределение заявок по видам сопровождения.

Переключатель темы находится справа вверху. Выбранная тема сохраняется после перезапуска страницы.

## Хранение данных

Для хранения используется localStorage. Не очищайте данные сайта, если хотите сохранить введённые записи. При повреждении сохранённых данных приложение возвращается к учебному набору. Синхронизации между браузерами и серверной авторизации в этой версии нет.

## Если возникла проблема

Проверьте, что локальный сервер запущен из корня проекта. Откройте инструменты разработчика Chrome (F12) и вкладку Console. Проверку можно повторить командой `python tests/verify_ui.py` при установленном Selenium. Замечания записывайте в `tests/RESULTS.md` или в GitHub Issues после настройки публикации.
