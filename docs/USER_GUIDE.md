# Руководство пользователя Smart Support Hub

## Назначение

Приложение помогает небольшой команде видеть внедрения, обращения пользователей, изменения продукта и историю выпусков. Это демонстрационная версия для лабораторной работы.

## Запуск и главное меню

Откройте `index.html` через локальный HTTP-сервер. Слева находятся пять разделов: Панель, Внедрения, Инциденты, Заявки, Релизы. На телефоне меню раскрывается кнопкой в верхнем левом углу. Переключатель темы расположен справа вверху.

## Как зарегистрировать инцидент

1. Откройте «Инциденты».
2. Введите название обращения и выберите приоритет.
3. Нажмите «Зарегистрировать». Появится запись со статусом «Новый».
4. Для обработки нажмите «В работу». Когда проблема устранена, нажмите «Решить».
5. Поле SLA покажет «В срок», «Просрочен» либо «Решён вовремя». На панели обновятся соответствующие показатели.

Если название пустое, запись не создаётся. Для поиска используйте поле «Поиск» и фильтры справа над таблицей.

## Как добавить внедрение

В разделе «Внедрения» заполните данные заказчика, продукта, версии, ответственного, этап, плановую дату и число задач. Используйте кнопки «Следующий этап» и «+ задача» для изменения готовности. Количество выполненных задач не должно превышать общего числа.

## Как создать заявку на изменение

Откройте «Заявки», напишите название, выберите один из четырёх видов сопровождения и целевую версию. Статус можно последовательно перевести в план или сразу отметить выполнение. На главной панели график учитывает добавленную заявку.

## Как выпустить версию

В «Релизах» выберите Patch, Minor или Major. Справа появится новый номер по SemVer. Укажите дату и перечислите изменения по одному на строке. После сохранения версия появится в истории и в верхней панели.

## Хранение данных

Изменения автоматически сохраняются в localStorage конкретного браузера. Если очистить данные сайта или открыть другой браузер, записи не перенесутся. Демо-данные загрузятся при первом запуске.

## Куда обратиться

По вопросам работы учебного проекта обратитесь к студенту, который его сдаёт, либо к преподавателю дисциплины. Никакие персональные данные вводить не нужно.
