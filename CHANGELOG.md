# Изменения Smart Support Hub

Изменения сгруппированы по версиям. Даты соответствуют выполнению лабораторной работы, без искусственной истории.

## [v1.1.0] — 03.11.2026

- Переделаны все пять страниц: спокойная графитовая тема, компактная боковая панель, более читаемые таблицы и единое оформление.
- Добавлены быстрые фильтры списка инцидентов: все, новые, в работе, решённые.
- Формы создания вынесены в отдельные модальные окна. Исправлена обработка выбора приоритета и закрытия диалога.
- Исправлена проверка названия инцидента: сообщение об ошибке исчезает после ввода.
- Chart.js подключается из локального файла. Два графика работают без внешнего CDN.
- Добавлена иконка сайта и устранены запросы, дававшие 404 в Chrome.
- Проверены формы, SLA, сохранение localStorage, переключение темы, SemVer и размеры 1366 / 768 / 390 пикселей.
- Автоматическая проверка интерфейса: 26 PASS, 0 FAIL; модульные проверки: 11 PASS, 0 FAIL.
- Замечания зарегистрированы в GitHub: [#1](https://github.com/t1ktakdev/smart-support-hub/issues/1), [#2](https://github.com/t1ktakdev/smart-support-hub/issues/2); оба исправления проверены локально.

## [v1.0.0] — 03.11.2026

- Первоначальный рабочий прототип с пятью отдельными HTML-страницами.
- Демонстрационные внедрения, инциденты, заявки и история релизов.
- Добавление записей, фильтры, расчёт SLA, четыре показателя и два графика.
- Хранение данных и настройки темы в браузере.

## Публикация

Исходники и оба тега подготовлены локально. Репозиторий GitHub создан, но публикация кода и GitHub Pages заблокирована политикой подключения ForgeBridge (`git.push` / `scope-deny`). До разрешения операции локальная версия является основной проверенной копией.
