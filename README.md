# Smart Support Hub

Учебный сервис-деск для небольшого отдела сопровождения: внедрения, инциденты, контроль SLA, заявки на изменения и релизы.

## Запуск на компьютере

Проект работает как статический сайт. Node.js и сборка не нужны.

```powershell
cd D:\smart-support-hub
python -m http.server 8765
```

Откройте http://127.0.0.1:8765/ в браузере. Для завершения локального сервера нажмите Ctrl+C в терминале.

## Разделы

| Страница | Назначение |
| --- | --- |
| `index.html` | Четыре показателя и два графика Chart.js |
| `deployments.html` | Внедрения, этапы и процент готовности |
| `incidents.html` | Обращения, приоритеты, фильтры и контроль SLA |
| `maintenance.html` | Четыре вида сопровождения и статусы заявок |
| `releases.html` | История выпусков и расчёт SemVer |

Данные и тема хранятся в localStorage текущего браузера. **Это учебная демонстрация, а не серверная система:** данные не синхронизируются между компьютерами, пользовательской авторизации нет. Не вводите реальные личные данные и секреты.

Сроки SLA: Critical 4 часа, High 8 часов, Medium 24 часа, Low 72 часа. Для завершённых инцидентов результат рассчитывается по фактической дате решения. Показатель SLA равен проценту решённых обращений, уложившихся в срок.

Два графика построены на Chart.js (MIT). Файл `assets/js/chart.umd.min.js` включён в исходники, поэтому для отображения графиков не требуется доступ к CDN.

## Проверка

```powershell
node tests/unit.js
python tests/verify_ui.py
```

Для браузерной проверки нужен запущенный локальный сервер на порту 8765 и установленный Python-пакет Selenium с Chrome. Проверки выполнялись в настоящем Google Chrome: **26 PASS, 0 FAIL**; модульные проверки: **11 PASS, 0 FAIL**.

Фактические результаты: `tests/results.json`, `tests/RESULTS.md`. Снимки настоящего браузера: `evidence/`. Для создания скриншотов тесты используют отдельный браузерный профиль, исходные демоданные не подменяются изображениями.
