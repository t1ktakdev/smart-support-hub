# Smart Support Hub

Учебное веб-приложение для учёта внедрений, инцидентов, заявок на сопровождение и выпусков программного продукта.

## Возможности

- Рабочая панель с четырьмя показателями и двумя графиками Chart.js.
- Список внедрений: добавление, переход к следующему этапу, отметка выполненных задач.
- Инциденты: добавление, приоритет, фильтрация, поиск, работа с заявкой и решение.
- Учебный расчёт SLA: critical 4 ч, high 8 ч, medium 24 ч, low 72 ч.
- Заявки четырёх видов и изменение статуса.
- История выпусков и расчёт следующей версии по SemVer.
- Сохранение записей и выбранной темы в localStorage. При некорректном JSON используется демонстрационный набор данных.
- Адаптивная вёрстка, навигация с клавиатуры, светлая и тёмная темы.

## Запуск

Никакой сборки и установки npm-пакетов не требуется. Для корректной работы откройте терминал в папке проекта и выполните:

```bash
python -m http.server 8000
```

В браузере перейдите на `http://localhost:8000`. Можно использовать расширение Live Server в VS Code. Для графиков нужна загрузка Chart.js с CDN (требуется интернет).

Данные остаются в вашем браузере, сервер не получает и не сохраняет записи. Начальные записи демонстрационные. Не вводите настоящие персональные данные.

## Проверка

В `tests/` находятся сценарии для браузера и тесты вычислений. Основные ручные сценарии: пустой инцидент, новый `high`, смена статуса, новая заявка `perfective`, обновление страницы, узкая мобильная ширина.

## Структура

- `index.html` — показатели, диаграммы, последние обращения.
- `deployments.html` — учёт внедрений.
- `incidents.html` — журнал инцидентов и SLA.
- `maintenance.html` — план изменений.
- `releases.html` — версии продукта.
- `assets/css/style.css` — стили.
- `assets/js/` — логика страниц, данные, хранение, расчёт SLA и SemVer.
- `docs/USER_GUIDE.md` — краткое руководство.
- `CHANGELOG.md` — история изменений приложения.

## Ограничения

Это фронтенд-прототип для учебного задания. Нет общего сервера и авторизации: записи одного браузера не видны на другом устройстве. SLA настроен как учебный расчёт без учёта рабочих дней. Графики требуют подключения к CDN Chart.js.
